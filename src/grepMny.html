About

Built for quick searches and clean student course records.

GrepMany started as a login, homepage, and student information form. The upgraded version turns that into a polished workspace with safer forms, stronger visual hierarchy, better mobile behavior, and clearer paths from sign in to registry submission.

What improved

Useful features, not just prettier screens.

01

Theme-aware interface

Light and dark modes are saved locally and applied across login, signup, dashboard, and registry pages.

02

Accessible navigation

Keyboard skip links, semantic landmarks, focus states, and a mobile menu make the site easier to use.

03

Validated submissions

Client-side checks catch empty fields, date mistakes, password mismatches, and invalid email formats early.

04

Safer PHP handlers

Prepared statements, server-side validation, session regeneration, and password hashing reduce common risks.

05

Pattern Lab

Test search terms against sample records before moving data into the registry workflow.

06

Deployment shape

Assets, PHP helpers, pages, and media now live in clearer folders so the project can grow.

Pattern Lab

Try a quick search before saving data.

Type a keyword or regular expression to search the sample course records. Invalid regular expressions fall back to plain text search.
