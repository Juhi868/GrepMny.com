# GrepMny

GrepMny is a simple and modern web application designed for managing student course records. It gives you a clean and easy-to-use workspace to:

- Find and search through student data quickly.
- Store and organize course records in one place.
- Validate information before it gets saved to the database, ensuring everything is correct.


# Features
- Easy Login & Registration: Secure access for all users.
- Responsive Design: Works beautifully on any device, large or small.
- Dark Mode Support: Toggle between light and dark themes for comfortable viewing.
- Clean Interface: Designed to make navigating and managing data as simple as possible.

## Project Structure

- `GrepMny.com/` - Contains the main web application files (HTML, CSS, JS, PHP).
  - `index.html` - The login and landing page for the application.
  - `assets/` - Stylesheets and frontend scripts.
  - `src/` - Additional pages like signup and password recovery.
  - `scripts/` - Backend logic, including PHP scripts for login and data processing.


# Getting Started
Since this project uses PHP for its backend, you can run it using a local server environment like XAMPP.
1. Make sure this project is placed inside your `htdocs` directory (e.g., `c:\xampp\htdocs\GrepMny`).
2. Start your Apache and MySQL servers via the XAMPP Control Panel.
3. Open your web browser and navigate to `http://localhost/GrepMny/GrepMny.com/`.
